# APEL-2025-2026-grille_paques
Vente de cases sous forme de grille de Pâques dans le cadre de l'APEL.

La grille est donnée sous deux styles : enfantin et ado.

# Outils
Ordinateur sous Windows 11.

L'affiche a été créée avec Word de la suite office 365. La grille a été créée en mode pleine page. Utilisation d'un publipostage pour ajouter les noms, prénoms et numéro de grille pour chaque grille. Impression de deux grilles par page.

Le fond de la grille a été créée grâce à chatgpt et gemini.

Police utilisée : "??"

# Pour modifier l'affiche
Ouvrir le fichier source (APEL-2025-2026-grille_paques.docx) avec Word.
